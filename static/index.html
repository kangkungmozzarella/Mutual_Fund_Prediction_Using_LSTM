Tentang model dan data
  • Data harian diambil dari Yahoo Finance lewat yfinance. Jika gagal, dashboard memakai CSV cadangan di folder data/.
  • Target prediksi adalah harga Close hari berikutnya. Fitur dinormalisasi MinMax berdasarkan data latih saja.
  • Forecast dibuat rekursif: setiap hasil prediksi dijadikan baris harga baru, lalu Average dan RSI dihitung ulang untuk langkah berikutnya.
  • Rentang perkiraan = ±1,96 × simpangan baku error data uji × √hari. Ini gambaran kasar ketidakpastian, bukan jaminan.
  • "vs tebakan naive" membandingkan RMSE model dengan tebakan paling sederhana: harga besok = harga hari ini. Nilai positif berarti model lebih baik.
  • Bukan saran investasi.
